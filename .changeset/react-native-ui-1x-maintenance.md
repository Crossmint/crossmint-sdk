1.x maintenance release for apps on Expo SDK 54 to 57, which cannot move to 2.x (Expo SDK 58). It brings the wallet, auth and signer fixes released since 1.9.3, and the embedded offramp. Dependencies, peer dependencies, the iOS native module and the config plugin are the same as in 1.9.3; only the `@crossmint/*` packages are newer. Install it with `npx expo install @crossmint/client-sdk-react-native-ui@v1`.
